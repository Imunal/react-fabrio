# react-fabrio

A lightweight, open-source React library for building intuitive product customization experiences.

Install dependencies with `pnpm install`; this also installs the Lefthook Git hooks.
Before each commit, Lefthook runs Oxlint and checks formatting with Oxfmt.

- `pnpm lint` runs Oxlint.
- `pnpm format` formats the project with Oxfmt.
- `pnpm format:check` checks formatting without changing files.
