# Playground photograph

`little-moments.png` is an original AI-generated demo photograph, created for this playground with OpenAI image generation. Source dimensions: 1536 × 1024 pixels. Its generation prompt is embedded in the PNG metadata. It is served locally and referenced as a durable design asset; it is not merchant photography or user-uploaded content.

The three text/vector templates are authored in `src/demo.ts`. Manrope is served from `public/fonts` with its accompanying OFL license; document text keeps the shared fixture's Fabrio Sans font.
